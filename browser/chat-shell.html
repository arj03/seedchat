    Pick a room name and share it with the peers you want to meet — only clients in the same room see each other. Leave empty for the default global room (allowed chars: A-Z a-z 0-9 . _ -).

    Random mints a private room and a contact secret, then Copy invite link gives you one URL carrying both. The secret lives in the link's # fragment, which browsers never send to a server — so the relay forwards your signaling without being able to join the room itself. A peer that cannot produce the secret draws no response at all. Without one the room is open: anyone who learns its name can join.

    Start a relay locally with node scripts/relay.mjs, or point at a public one your group trusts.
